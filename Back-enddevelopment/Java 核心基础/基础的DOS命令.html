基础的DOS命令（Windows命令提示符常用命令）

  • 以下是日常使用Windows时最实用、最常碰到的基础DOS命令，按功能分类整理：

1. 磁盘与路径操作

命令 作用 常用示例
dir 显示当前目录文件列表 dir /p dir /s dir *.java
cd 切换目录 cd .. cd \ cd d:\project
cd /d 切换盘符+目录（最常用写法） cd /d d:\code\java
md / mkdir 创建目录 md newfolder
rd / rmdir 删除空目录 rd oldfolder
del 删除文件 del *.tmp del /q /f *.class
copy 复制文件 copy file.txt d:\backup
move 移动文件/重命名 move 1.txt 2.txt
ren / rename 重命名文件或文件夹 ren old.txt new.txt

2. 系统信息与状态

命令 作用 常用示例
ipconfig 查看/刷新网络配置 ipconfig /all ipconfig /flushdns
ping 测试网络连通性 ping www.baidu.com ping -t 8.8.8.8
systeminfo 查看详细系统信息 systeminfo
whoami 显示当前登录用户名 whoami /all
ver 显示Windows版本 ver
time / date 查看或修改系统时间/日期 time date

3. 文件内容查看与编辑

命令 作用 常用示例
type 显示文本文件内容 type readme.txt
more 分页显示（配合管道使用） type large.log | more
cls 清空屏幕 cls
echo 显示文字或开启/关闭回显 echo hello echo.（空行）
echo. > 文件名 快速创建空文件 echo. > test.txt

4. 进程与服务相关

命令 作用 常用示例
tasklist 显示当前运行进程 tasklist /v tasklist /fi “imagename eq chrome*”
taskkill 结束进程 taskkill /im notepad.exe taskkill /pid 1234 /f
netstat 显示网络连接 netstat -ano
chkdsk 检查磁盘错误 chkdsk d: /f

5. 常用快捷组合

组合 作用
Tab键 自动补全文件名/命令
↑ / ↓ 翻看历史命令
Ctrl+C 中止当前命令
> 文件名 输出重定向到文件（覆盖）
>> 文件名 输出追加到文件
| 管道，把前面命令结果给后面命令
&& 前一条命令成功才执行后一条
& 不管前面成功与否都执行后面
