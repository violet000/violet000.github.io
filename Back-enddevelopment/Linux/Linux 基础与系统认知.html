一、Linux 是什么？

1. 操作系统的概念

操作系统（Operating System，OS）是一种管理硬件与软件资源的系统软件，负责管理硬件（CPU、内存、磁盘、设备）提供运行应用程序的环境，提供用户与硬件交互的接口

2. Linux 的定义

Linux 是一个开源、类 Unix 的操作系统内核

完整的 Linux 系统 = Linux 内核 + GNU 工具链 + 应用软件

3. Linux 的重要特性

  • 开源（Open Source）
  • 多用户、多任务
  • 高稳定性与高安全性
  • 强大的网络能力
  • 跨平台支持多种 CPU 架构

二、Linux 的整体架构

+-------------------------+
|   用户应用层 (APP)      |
+-------------------------+
|   Shell / 命令解释器     |
+-------------------------+
|   系统调用接口 (glibc)  |
+-------------------------+
|   Linux 内核层           |
|   - 进程调度             |
|   - 内存管理             |
|   - 文件系统             |
|   - 驱动程序             |
+-------------------------+
|   硬件层                 |
+-------------------------+

1. 用户空间（User Space）

  • 应用程序
  • Shell
  • 基本命令工具

2. 内核空间（Kernel Space）

  • 进程管理
  • 内存管理
  • 文件系统
  • 设备驱动
  • 网络协议栈

三、常见 Linux 发行版

类型 发行版 特点

服务器 RHEL、Rocky Linux 稳定、安全
桌面 Ubuntu、Mint 入门友好
极客 Arch、Gentoo 高度可定制
容器 Alpine 体积极小

四、核心概念：内核态与用户态

1. 用户态（User Mode）

  • 权限受限
  • 不能直接操作硬件

2. 内核态（Kernel Mode）

  • 最高权限
  • 管理系统资源

3. 状态切换过程

用户程序 → 系统调用 → 进入内核态 → 返回用户态

五、面试题

1. Linux 的核心优势

  • 开源免费
  • 稳定可靠
  • 安全性高
  • 服务器占有率高

2. 什么是内核态与用户态？

  • 用户态运行普通程序
  • 内核态运行内核代码
  • 通过系统调用实现切换
