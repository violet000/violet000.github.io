规则：

  • 等号两边不能有空格：name = "Tom" 是错误写法
  • **访问变量使用 $变量名**：$name
  • 建议加双引号，避免空格、通配符等问题：echo "$name"

1.3 条件判断

常见数值比较运算符：

表达式 含义
-eq 等于
-ne 不等于
-gt 大于
-lt 小于
-ge 大于等于
-le 小于等于

文件判断：

表达式 含义
-f file 是否为普通文件
-d dir 是否为目录
-e path 是否存在

💡 条件判断中变量建议加上引号：[ -f "$file" ]

  • -u：使用未定义变量时报错
