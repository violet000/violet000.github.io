一、Linux 文件系统基础

Linux 文件系统采用 树形结构，最顶层为根目录/。所有文件与设备都在此树结构下。

1.1 根目录结构含义

目录 含义

/ 根目录
/bin 基本命令（普通用户可执行）
/sbin 系统管理命令（root 使用）
/etc 配置文件目录
/home 普通用户家目录
/root 超级管理员家目录
/var 变量数据（日志、缓存、队列）
/tmp 临时文件
/usr 系统软件资源目录
/lib 库文件
/boot 启动引导文件
/dev 设备文件
/proc 内核与进程信息（伪文件系统）

1.2 绝对路径与相对路径

✅ 绝对路径

  • 从根目录 / 开始
  • 示例：
    • /home/user/file.txt
    • /etc/ssh/sshd_config

✅ 相对路径

  • 相对于当前工作目录
  • 特殊符号：
    • . 当前目录
    • .. 上一级目录
  • 示例：
    • ../logs
    • ./script.sh

二、文件与目录操作命令

2.1 路径与位置查看

🔹 查看当前目录

pwd

🔹 切换目录

cd /etc
cd ~
cd ..

🔹 查看目录内容

ls
ls -l
ls -a
ls -lh

2.2 文件与目录创建

🔹 创建文件

touch file.txt

🔹 创建目录

mkdir test
mkdir -p a/b/c

2.3 复制、移动与删除

🔹 复制

cp file1 file2
cp -r dir1 dir2

🔹 移动或重命名

mv old new
mv file /tmp/

🔹 删除

rm file
rm -r dir
rm -rf dir

⚠️ rm -rf / 会删除系统，请务必慎用

三、权限管理

Linux 中每个文件都具有以下信息： - 所有者 - 所属组 - 访问权限

3.1 权限含义 rwx

r  读  read
w  写  write
x  执行 execute

示例：

-rwxr-xr--  1 root root  4096  test.sh

字段 含义

rwx 文件所有者权限
r-x 所属组权限
r– 其他用户权限

3.2 权限数字表示法

权限 数值

r 4
w 2
x 1
rwx 7
rw- 6
r– 4

示例：

chmod 755 file
chmod 644 file

3.3 修改权限/所有者/用户组

🔹 修改权限

chmod 755 file

🔹 修改所有者

chown user file

🔹 修改所属组

chgrp group file

四、查找与统计命令

4.1 find 查找文件

按名称查找：

find /etc -name "*.conf"

按大小查找：

find / -size +100M

按类型查找：

find . -type f
find . -type d

4.2 grep 查找内容

查找包含某关键字行：

grep "root" /etc/passwd

忽略大小写：

grep -i

显示行号：

grep -n

4.3 wc 统计

wc -l file      # 行
wc -w file      # 单词
wc -c file      # 字节

4.4 sort 排序

sort file
sort -r file

4.5 uniq 去重

uniq file
uniq -c file

4.6 cut 按列截取

cut -d: -f1 /etc/passwd

4.7 awk 处理行列

awk '{print $1,$3}' file

4.8 sed 流编辑器

sed 's/root/admin/g' file

五、经典面试题与答案

1️⃣ 如何查找文件中包含某个关键字的行？

答：使用 grep

grep "关键字" 文件名

递归目录：

grep -r "关键字" 目录

2️⃣ 如何统计一个目录下所有文件大小？

答：使用 du

du -sh *

统计当前目录总大小：

du -sh .
