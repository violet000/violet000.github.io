五、常见面试题

1️⃣ 如何查看当前服务器开启了哪些端口？

答案： 有多种方法可以查看监听端口

方法1：使用 ss（推荐）

方法2：使用 netstat

方法3：使用 lsof

方法4：查看特定端口

2️⃣ 如何判断服务器能否访问远程地址？

答案： 按照网络层次从下到上逐步排查

第一步：测试网络层连通性（ICMP）

如果 ping 不通，检查：

  • 网络配置是否正确
  • 防火墙是否阻止
  • 路由是否可达

第二步：测试传输层端口连通性（TCP/UDP）

第三步：测试应用层服务（HTTP/HTTPS）

第四步：抓包分析（深入排查）

排查思路总结：

  1. 网络层（ping）→ 2. 传输层（telnet/nc）→ 3. 应用层（curl）→ 4. 抓包分析

✅ 学习建议

  • 熟练掌握常用命令组合：ss/netstat/lsof 的组合使用
  • 实践抓包分析：使用 tcpdump 观察 TCP 三次握手、四次挥手过程
  • 记忆常见端口：
    • 80 - HTTP
    • 443 - HTTPS
    • 22 - SSH
    • 3306 - MySQL
    • 6379 - Redis
    • 8080 - 常用 Web 服务端口
  • 建立排错思维：按照网络层次（物理层→网络层→传输层→应用层）逐步排查
  • 编写排错 checklist：总结常见网络问题的排查步骤
