一、用户与组管理

Linux 中一切权限都围绕 用户（user） 与 组（group） 展开。

1.1 常用用户管理命令

命令 作用
useradd 新建用户
userdel 删除用户
passwd 设置或修改用户密码
usermod 修改用户属性
groupadd 新建用户组

二、文件权限控制

Linux 采用 拥有者 + 组 + 其他人 三类身份管理权限。

2.1 文件权限 rwx

权限 含义
r 读（read）
w 写（write）
x 执行（execute）

四、典型面试题

1️⃣ 普通用户如何执行只有 root 才能执行的命令？

答：

  • 使用 sudo
  • 需在 /etc/sudoers 中授权（通过 visudo 编辑）
  • 不能通过直接修改 /etc/passwd 来提权

2️⃣ 文件权限 755 与 644 含义

755

身份 权限
拥有者 rwx
组用户 r-x
其他人 r-x

👉 常用于目录、可执行脚本。

👉 常用于文本文件、配置文件（拥有者可读写，其他人只读）。
