一、运算符类型

1. 算术运算符

基本运算符： +、-、*、/、%

注意事项：

  • 整数相除结果仍为整数（向下取整）
  • 取余运算符 % 的结果符号与被除数相同
  • 字符串使用 + 进行拼接

2. 赋值运算符

基本赋值： =
复合赋值： +=、-=、*=、/=、%=

3. 自增自减运算符

前缀形式： ++变量、--变量（先运算后使用）
后缀形式： 变量++、变量--（先使用后运算）

4. 关系运算符

运算符： >、<、>=、<=、==、!=

关系运算符返回 boolean 类型的值（true 或 false）。

5. 逻辑运算符

运算符： &&（逻辑与）、||（逻辑或）、!（逻辑非）

运算符 名称 说明
&& 逻辑与 两个条件都为 true 时结果为 true，具有短路特性
|| 逻辑或 两个条件有一个为 true 时结果为 true，具有短路特性
! 逻辑非 取反，true 变 false，false 变 true

短路特性说明：

  • &&：如果第一个条件为 false，不会执行第二个条件
  • ||：如果第一个条件为 true，不会执行第二个条件

6. 位运算符

运算符： &（按位与）、|（按位或）、^（按位异或）、~（按位取反）、<<（左移）、>>（右移）、>>>（无符号右移）

应用场景：

  • 位运算常用于性能优化和底层操作
  • 左移 << 相当于乘以2的n次方
  • 右移 >> 相当于除以2的n次方（向下取整）

7. 三目运算符（条件运算符）

语法： 条件 ? 表达式1 : 表达式2

8. instanceof 运算符

作用： 用于判断对象是否为指定类的实例

⭐ 重点：== 与 equals() 的区别

比较方式 含义 适用场景
== 比较两个变量是否指向同一块内存地址（引用比较） 基本类型比较值，引用类型比较地址
equals() 比较内容是否相同（可被重写） 引用类型的内容比较

注意事项：

  • String、Integer、Long 等包装类重写了 equals() 方法
  • 自定义类需要重写 equals() 方法才能正确比较内容
  • 重写 equals() 时通常也要重写 hashCode() 方法

二、控制语句

1. 条件语句

if / else / else if

switch 支持的类型：

  • byte、short、int、char（JDK 1.0+）
  • enum（JDK 5.0+）
  • String（JDK 7.0+）
  • 包装类型（JDK 5.0+，会自动拆箱）

注意事项：

  • case 标签必须是常量或字面量
  • 每个 case 后通常需要 break，否则会继续执行下一个 case（case穿透）
  • default 子句可以放在任意位置，但通常放在最后

三、循环语句

1. for 循环

基本语法： for (初始化; 条件判断; 迭代) { 循环体 }

2. 增强 for 循环（for-each）

语法： for (元素类型 变量名 : 数组或集合) { 循环体 }

注意事项：

  • 增强 for 循环不能修改集合/数组的元素值
  • 无法获取当前元素的索引
  • 不能用于删除集合元素（会抛出 ConcurrentModificationException）

3. while 循环

语法： while (条件) { 循环体 }

4. do…while 循环

语法： do { 循环体 } while (条件);

while 与 do…while 的区别：

  • while：先判断条件，条件为 true 才执行循环体
  • do...while：先执行循环体，再判断条件，至少执行一次

四、控制跳转语句

1. break

作用： 跳出当前循环或 switch 语句

2. continue

作用： 跳过本次循环，继续下一次循环

3. return

作用： 结束当前方法，可以返回值

4. 标签（Label）的使用

作用： 配合 break 和 continue 使用，可以跳出或继续指定的循环

五、面试常见问题

1. == 与 equals() 的区别？

答案：

  • == 是运算符，用于比较基本类型的值或引用类型的地址
  • equals() 是方法，用于比较对象的内容，可以被重写
  • 对于基本类型，只能使用 == 比较
  • 对于引用类型，== 比较地址，equals() 比较内容（如果重写了）

扩展：

  • String 类重写了 equals() 方法
  • 自定义类重写 equals() 时，通常也要重写 hashCode() 方法
  • 字符串常量池的特殊性

2. switch 能否作用于 String？从哪个版本开始支持？

答案：

  • JDK 7 以后开始支持 String 类型
  • 实现原理：通过 hashCode() 和 equals() 方法进行比较
  • 需要注意 case 标签不能为 null

3. while 与 do…while 的区别？

答案：

  • while：先判断条件，条件为 true 才执行循环体（可能一次都不执行）
  • do...while：先执行循环体，再判断条件（至少执行一次）

4. break 和 continue 的区别？

答案：

  • break：跳出当前循环或 switch 语句
  • continue：跳过本次循环，继续下一次循环
  • 两者都可以配合标签使用，控制外层循环

5. 逻辑运算符 && 和 & 的区别？

答案：

  • && 是逻辑运算符，具有短路特性，只能用于 boolean 类型
  • & 是位运算符，也可以用于逻辑运算，但不具有短路特性
  • 推荐使用 && 和 ||，因为具有短路特性，性能更好

6. 自增运算符 i++ 和 ++i 的区别？

答案：

  • i++：后缀形式，先使用变量的值，再进行自增
  • ++i：前缀形式，先自增，再使用变量的值
  • 单独使用时效果相同，但在表达式中使用时效果不同

7. for 循环和增强 for 循环的区别？

答案：

  • for 循环可以获取索引，可以修改数组/集合元素
  • 增强 for 循环语法简洁，但无法获取索引，不能修改元素
  • 增强 for 循环不能用于删除集合元素（会抛出异常）

8. switch 语句中 case 穿透是什么？

答案：

  • 当 case 标签后没有 break 语句时，会继续执行下一个 case 的代码
  • 这叫做 case 穿透
  • 可以利用 case 穿透实现多个 case 共享同一段代码
  • 箭头语法（case ->）不会发生 case 穿透
