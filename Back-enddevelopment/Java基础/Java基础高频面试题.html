📌 高频面试题系列 1（1–6）

1. == 和 equals 的区别？

  • ==
    • 比较基本数据类型：值是否相等
    • 比较引用类型：是否指向同一对象（地址是否相同）
  • equals()
    • Object 默认实现：与 == 一样
    • 常被重写用于比较内容是否相同（如 String、Integer）

👉 口诀：

  • 基本类型：== 比值
  • 引用类型：== 比地址，equals 比内容

2. 成员变量与局部变量的区别？

比较项 成员变量 局部变量
作用范围 整个类 方法/代码块内
是否有默认值 有 无，必须先初始化
修饰符 可有权限修饰符 不能使用权限修饰符
存储位置 堆 栈
生命周期 随对象 随方法调用

3. 面向对象三大特性及实际应用？

  • 封装：隐藏实现 → 提供接口（private 属性 + getter/setter）
  • 继承：复用父类代码 → extends
  • 多态：父类引用指向子类对象 → 提高扩展性

实际应用：

  • 模板模式、策略模式、Spring IOC 都离不开多态

4. String 为什么不可变？intern() 原理？

不可变原因：

  • 底层 char[] 被 final 修饰
  • String 被 final 修饰
  • 设计为不可变 → 线程安全、常量池复用，提高效率

intern()：

  • 把字符串放入字符串常量池
  • 若常量池已存在，返回池中对象引用

5. ArrayList 扩容机制？

  • 默认容量 10
  • 触发条件：size == capacity
  • 扩容：newCapacity = oldCapacity * 1.5
  • 底层使用 数组复制 System.arraycopy()

6. HashMap 底层原理？如何解决哈希冲突？负载因子？

  • JDK 1.7：数组+链表
  • JDK 1.8：数组+链表+红黑树
  • 哈希冲突：拉链法（链表/红黑树）
  • 扩容条件：
    • threshold = capacity * loadFactor
    • 默认负载因子 0.75

📌 高频面试题系列 2（7–12）

7. final、finally、finalize 的区别？

  • final：修饰类/方法/变量，表示不可变
  • finally：异常处理中一定执行
  • finalize：GC 回收前调用（已过时，不推荐使用）

8. ArrayList 和 LinkedList 区别？

项目 ArrayList LinkedList
底层结构 动态数组 双向链表
查询 快 慢
增删 慢 快
空间利用 连续空间 离散空间

9. Set 为什么不能存重复元素？HashSet 原理？

  • 因为依赖：哈希值 + equals()
  • HashSet 底层基于 HashMap
  • 判断重复：
    1. hashCode 相同
    2. equals() 返回 true

10. 接口和抽象类的区别？

维度 抽象类 接口
关键字 abstract class interface
继承实现 单继承 多实现
成员 可有成员变量 默认常量
默认方法 支持 Java8 支持 default
设计思想 模板 规范

11. throw 与 throws 区别？

  • throw：方法内主动抛异常
  • throws：声明方法可能抛出异常

自定义异常：继承 Exception/RuntimeException

12. finally 中 return 会覆盖 try 吗？

👉 会！
try 和 catch 中的 return 会被 finally 中的 return 覆盖
⚠️ 实际开发：不要在 finally 中写 return

📌 包装类专项（13–15）

13. int 和 Integer 的区别？为什么推荐包装类？

  • int：基本类型
  • Integer：包装类型
  • 包装类优点：
    • 可用于集合
    • 可为 null
    • 提供方法支持

14. Integer.valueOf() 与 new Integer() 区别？

  • new Integer()：一定新建对象
  • valueOf()：可能使用缓存

15. Integer 缓存机制？

  • 范围：[-128, 127]
  • 存放于 IntegerCache 中
  • 超过范围 → 新建对象
  • 目的：节省内存，提高效率
