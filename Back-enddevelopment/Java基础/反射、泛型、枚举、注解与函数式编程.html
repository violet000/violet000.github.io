反射、泛型、枚举、注解与函数式编程

  • BACK-ENDDEVELOPMENT
  • JAVA基础
  • 反射、泛型、枚举、注解与函数式编程

一、反射（Reflection）

1.1 概念

  • 在运行时动态获取类的信息并操作对象（字段、方法、构造器等）
  • 反射是 Spring、MyBatis、JUnit 等框架的基础能力

1.2 获取 Class 对象的方式

1.3 常用反射 API

  • Class：类的元数据入口
  • Constructor：构造器
  • Method：方法
  • Field：字段

1.4 动态创建对象与调用方法

应用场景：

  • IOC 容器（按配置创建对象）
  • 动态代理
  • 配置驱动 / 插件化

1.5 反射的优缺点

  • 优点：动态、灵活、解耦（配置驱动）
  • 缺点：性能开销、类型安全检查延后到运行期；要注意权限与安全管理

二、泛型（Generics）

2.1 为什么需要泛型？

  • 类型安全：编译期检查，避免 ClassCastException
  • 可读性与复用性：减少显式强制类型转换

2.2 泛型类与泛型方法

2.3 通配符 ?、extends、super

  • <?>：任意类型
  • <? extends T>：上界通配符（读为主，Producer）
  • <? super T>：下界通配符（写为主，Consumer）
  • 口诀：PECS（Producer extends，Consumer super）

2.4 类型擦除机制（核心考点）

  • 编译后，泛型信息被擦除为 Object 或边界类型
  • 运行时不存在具体泛型类型参数
  • 影响：
    • 不能 new T[]
    • 不能 instanceof T
    • 重载可能因擦除导致签名冲突

面试常问：“Java 泛型是伪泛型吗？” → 是“类型擦除式泛型”，编译期检查 + 运行期擦除。

三、枚举（Enum）

3.1 作用

  • 表示固定常量集合，类型安全，可读性强
  • 天然单例（每个枚举值在 JVM 中只有一个实例）

3.2 基本用法与原理

  • 本质是一个继承 java.lang.Enum 的类
  • 可定义字段、方法、构造器（构造器默认 private）

面试常问：“枚举为什么是线程安全的单例？” → JVM 在类加载阶段完成实例创建，且实例是 final 的。

四、注解（Annotation）

4.1 注解的用途

  • 元数据：为代码添加说明信息
  • 替代配置文件：让框架通过反射 / 注解处理器读取并执行特定逻辑
  • 广泛用于 Spring、JPA、JUnit、Lombok 等框架

4.2 元注解（定义注解的注解）

  • @Target：作用位置（TYPE、METHOD、FIELD、PARAMETER 等）
  • @Retention：生命周期（SOURCE / CLASS / RUNTIME）
  • @Documented
  • @Inherited

4.3 自定义注解示例

处理方式：

  • 运行时：通过反射读取注解信息
  • 编译期：通过注解处理器（APT）生成代码或做校验（如 Lombok、MapStruct）

五、函数式编程与 Lambda

5.1 函数式接口（Functional Interface）

  • 只包含一个抽象方法的接口
  • 使用 @FunctionalInterface 标注（可选但推荐）

常见接口：

  • Runnable
  • Callable
  • Supplier<T>
  • Consumer<T>
  • Function<T, R>
  • Predicate<T>

5.2 Lambda 表达式

  • 作用：简化匿名内部类，提升可读性
  • 语法：(参数列表) -> { 方法体 }

5.3 组合式函数接口（以 java.util.function 为例）

  • Function：andThen、compose
  • Predicate：and、or、negate
  • Consumer：andThen

5.4 Stream 流

  • 对集合进行链式、声明式操作的 API
  • 典型流程：创建流 → 中间操作（惰性）→ 终止操作（触发执行）

常见操作：

  • 中间操作：map、filter、sorted、distinct、limit、skip
  • 终止操作：forEach、reduce、collect、count、anyMatch、findFirst

5.5 Optional 可选值

  • 用于显式表达“值可能为空”
  • 避免直接返回 null，减少 NullPointerException

Optional 适合返回值，不建议在成员变量、序列化对象、集合元素中滥用。

六、高频面试与实践要点

  • 反射：优点（动态、解耦）与缺点（性能、安全）；Class 获取方式；常用 API；框架中的典型使用场景
  • 泛型：PECS 口诀；类型擦除的影响（不能 new T[]、instanceof 受限、重载冲突）；为何 Java 采用擦除式泛型
  • 枚举：为何天然单例、线程安全；可自定义字段与方法；与常量类的对比
  • 注解：元注解作用；自定义注解 + 反射 / APT 处理；常见框架的注解驱动
  • 函数式编程：函数式接口定义；Lambda 语法；Stream 流的中间/终止操作；Optional 的正确使用

✅ 学习与练习建议

  • 多写小例子：反射创建对象 + 调用方法；自定义注解 + 反射读取；Lambda 与 Stream 的组合管道
  • 背口诀：泛型 PECS；Stream“创建 → 中间（惰性）→ 终止（触发）”
  • 关注性能与边界：反射的性能成本；Stream 终止操作才执行；Optional 不要滥用在成员变量
  • 结合源码（java.lang.reflect、java.util.function、java.util.stream）阅读，加深理解
