一、Java 基础语法

1. 标准类结构

说明：

  • public：访问修饰符，表示该类是公开的
  • class：关键字，用于声明类
  • HelloWorld：类名，必须与文件名一致（首字母大写）
  • main 方法：Java 程序的入口点，方法签名必须严格匹配

2. 包与导入

注意事项：

  • 包名通常使用小写字母，多个单词用点号分隔
  • 包声明语句必须在文件最前面（注释除外）
  • 可以使用通配符 * 导入包下所有类，但不推荐

3. 注释

4. 命名规范

Java 采用驼峰命名法（CamelCase）：

类型 命名规范 示例
类名 大驼峰（PascalCase），首字母大写 StudentInfo、UserService
方法名 小驼峰（camelCase），首字母小写 getStudentName()、calculateTotal()
变量名 小驼峰（camelCase），首字母小写 studentName、totalCount
常量 全大写，单词间用下划线分隔 MAX_VALUE、DEFAULT_SIZE
包名 全小写，单词间用点号分隔 com.example.util

命名注意事项：

  • 不能使用 Java 关键字作为标识符
  • 不能以数字开头
  • 可以使用字母、数字、下划线（_）和美元符号（$）
  • 区分大小写

二、Java 数据类型

1. 基本数据类型（Primitive Types）

Java 有 8 种基本数据类型：

整数类型

类型 大小 取值范围 默认值 示例
byte 1 字节 -128 ~ 127 0 byte b = 100;
short 2 字节 -32,768 ~ 32,767 0 short s = 1000;
int 4 字节 -2³¹ ~ 2³¹-1 0 int i = 100000;
long 8 字节 -2⁶³ ~ 2⁶³-1 0L long l = 100000L;

浮点类型

类型 大小 精度 默认值 示例
float 4 字节 7 位有效数字 0.0f float f = 3.14f;
double 8 字节 15-17 位有效数字 0.0d double d = 3.14159;

字符类型

类型 大小 取值范围 默认值 示例
char 2 字节 ‘\u0000’ ~ ‘\uffff’ (0 ~ 65535) ‘\u0000’ char c = 'A';

布尔类型

类型 大小 取值范围 默认值 示例
boolean JVM 实现相关 true 或 false false boolean flag = true;

2. 包装类（Wrapper Classes）

每个基本数据类型都有对应的包装类：

基本类型 包装类 说明
byte Byte 字节类型包装类
short Short 短整型包装类
int Integer 整数类型包装类
long Long 长整型包装类
float Float 单精度浮点包装类
double Double 双精度浮点包装类
char Character 字符类型包装类
boolean Boolean 布尔类型包装类

包装类的作用：

  • 将基本类型转换为对象，可以存储在集合中
  • 提供丰富的工具方法
  • 支持 null 值
