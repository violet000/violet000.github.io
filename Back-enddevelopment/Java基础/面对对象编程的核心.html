面向对象编程核心

  • BACK-ENDDEVELOPMENT
  • JAVA基础
  • 面对对象编程的核心

一、类与对象（Class & Object）

1.1 什么是类？

  • 类是对一类事物的抽象描述
  • 是对象的模板 / 蓝图
  • 一个类中通常包含：
    • 成员变量（属性 / 状态）
    • 成员方法（行为）
    • 构造方法
    • 内部类等

1.2 什么是对象？

  • 对象是类的具体实例
  • 通过 new 关键字在堆内存中创建
  • 每个对象拥有自己的一份属性值，但共享同一个类的结构

1.3 构造方法（Constructor）

  • 名称与类名相同
  • 没有返回值类型（连 void 都不能写）
  • 作用：在创建对象时完成初始化工作

分类：

  • 无参构造方法（默认构造）
  • 有参构造方法（方便直接初始化属性）
  • 构造方法可以重载

一旦手动写了任何构造方法，JVM 就不会再自动提供无参构造，这是常见考点。

1.4 this 关键字

  • this 指向当前对象本身
  • 常见用途：
    • 区分成员变量与局部变量同名
    • 在一个构造方法中调用本类的另一个构造方法：this(...)
    • 在方法内部将当前对象传递出去：return this;

1.5 方法重载（Overload）

  • 同一类中，方法名相同，参数列表不同 -> 构成重载
  • 参数不同体现在：
    • 个数不同
    • 类型不同
    • 顺序不同
  • 与返回值类型无关，仅靠返回值不同不能构成重载

1.6 static 关键字

作用：

  • 修饰成员变量 → 静态变量（类变量）
  • 修饰成员方法 → 静态方法
  • 修饰代码块 → 静态代码块

特点：

  • 属于类本身，不属于某个具体对象
  • 随类的加载而加载，全局唯一一份
  • 推荐通过类名.成员访问：ClassName.staticField
  • 静态方法中不能直接访问非静态成员（因为此时可能还没有对象）

1.7 final 关键字

含义：不可改变

  • 修饰变量：成为常量（只能赋值一次）
  • 修饰方法：方法不可被子类重写
  • 修饰类：类不可被继承

常见面试例子：final class String —— String 不能被继承，且内部很多字段是 final，保证不可变性与线程安全性。

二、封装、继承、多态

2.1 封装（Encapsulation）

核心思想：

  • 隐藏实现细节
  • 对外只暴露必要的、受控的接口

典型做法：

  • 成员变量私有化：private
  • 提供 getter/setter 方法访问或修改

2.2 访问修饰符

修饰符 同类 同包 子类 其他包
private ✔ ✖ ✖ ✖
默认（无修饰符）default ✔ ✔ ✖ ✖
protected ✔ ✔ ✔ ✖
public ✔ ✔ ✔ ✔

记忆：从 private 到 public，访问范围逐步放大。

2.3 继承（Inheritance）

  • 使用关键字 extends
  • 子类自动拥有父类中非私有的成员（字段 + 方法）
  • 构造方法不能继承，但子类构造必须优先调用父类构造

注意事项：

  • Java 不支持多继承（一个类只能有一个直接父类）
  • 私有成员对子类不可见但实际存在
  • 尽量避免过深的继承层级，影响可维护性

2.4 方法重写（Override）

重写条件：

  • 方法名相同
  • 参数列表相同
  • 返回值类型相同或是父类返回值类型的子类型（协变返回）
  • 访问权限不能变小（可以变大）

注解：

  • @Override 强烈推荐写，可以在编译期检查是否真正发生了重写

2.5 多态（Polymorphism）

前提：

  • 存在继承关系
  • 存在方法重写
  • 父类引用指向子类对象

调用规则：

  • 编译看左边（引用的声明类型）—— 能调哪些方法
  • 运行看右边（实际对象类型）—— 具体执行哪个实现

多态能让“写代码依赖父类（接口），运行时自动调用子类实现”，是面向对象设计的核心。

三、面试重点（高频面试题）

3.1 成员变量与局部变量的区别

  • 所在位置不同
    • 成员变量：定义在类中、方法外
    • 局部变量：方法内、代码块内、形参等
  • 生命周期不同
    • 成员变量：随对象创建而存在，随对象消失而销毁
    • 局部变量：随方法调用而创建，方法结束后销毁
  • 是否有默认值
    • 成员变量：有默认值（如 int 默认 0，引用类型默认 null）
    • 局部变量：必须先赋值再使用，否则编译报错
  • 存储位置不同
    • 成员变量：随对象一起在堆中
    • 局部变量：一般在栈中

3.2 final、static 的使用场景

  • static
    • 工具类方法：如 java.lang.Math 中的大量静态方法
    • 共享数据：计数器、全局配置等
    • 结合 final 一起使用：public static final 定义全局常量
  • final
    • 常量：如 public static final int MAX_SIZE = 100;
    • 设计为不可被继承的类：如工具类、安全相关类
    • 不希望被子类修改实现的方法：final void method() {}（模板方法模式中常见）

3.3 面向对象三大特性解释

  • 封装：把数据和操作数据的方法绑定在一起，对外隐藏内部实现，只暴露必要接口
  • 继承：子类在保留父类特性的基础上进行扩展，实现代码复用与复用行为
  • 多态：同一父类引用指向不同子类对象时，调用同一个方法表现出不同的行为

✅ 学习建议

  • 多写代码练习：自己动手写类、构造方法、继承与多态，而不是只看概念
  • 画图理解继承与多态：画出父类、子类、对象、引用之间的关系
  • 多总结面试题与关键字作用：如 this / super / static / final / override / overload
  • 适当阅读 JDK 源码（如 String、ArrayList），体会关键字在真实项目中的用法
