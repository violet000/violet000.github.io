1. 泛型（Generics）

1.1 为什么需要泛型

  • 提供类型安全：编译期检查，避免强转和 ClassCastException
  • 代码复用与可读性：减少重复代码和显式强转

1.2 泛型类与泛型方法

1.3 通配符：?、extends、super

  • <?>：任意类型
  • <? extends T>：上界通配符，读为主（Producer）
  • <? super T>：下界通配符，写为主（Consumer）
  • 口诀：PECS（Producer extends, Consumer super）

1.4 类型擦除（核心考点）

  • 编译后泛型信息被擦除为 Object 或边界类型
  • 运行时不存在具体泛型参数
  • 影响：
    • 不能 new T[]
    • 不能 instanceof T
    • 重载可能因擦除导致签名冲突

面试常问：Java 采用擦除式泛型（编译期检查，运行期擦除）。

1.5 Optional 可选类型（简述）

  • 显式表示“值可能不存在”
  • 用于返回值，避免直接返回 null

2. 异常处理

2.1 try-catch-finally 基础

  • try 包裹可能异常的代码
  • catch 捕获并处理
  • finally 释放资源（几乎总会执行，除 System.exit 等极端情况）

2.2 throw 与 throws

  • throw：在方法内部主动抛出异常对象
  • throws：在方法签名声明可能抛出的异常，交由调用者处理

2.3 多异常捕获与顺序

  • 子类异常在前，父类异常在后
  • JDK 7+ 支持多异常合并：catch (IOException | SQLException e)

2.4 自定义异常与异常链

3. Java 8+ 新特性速览

3.1 Lambda 表达式

  • 作用：替代匿名内部类，简化语法
  • 形式：(参数) -> { 方法体 }

3.2 函数式接口（@FunctionalInterface）

  • 只包含一个抽象方法
  • 常见接口：Predicate、Function、Consumer、Supplier、Runnable、Callable
  • 组合方法：andThen、compose、and、or、negate

3.3 Stream API（集合的函数式操作）

  • 流程：创建流 → 中间操作（惰性）→ 终止操作（触发）
  • 常用中间操作：map、filter、sorted、distinct、limit/skip
  • 常用终止操作：forEach、collect、reduce、count、anyMatch/findFirst

3.4 Optional（防御 NPE）

  • ofNullable、orElse、orElseGet、map、flatMap
  • 避免把 Optional 用作字段或集合元素，主要用于返回值

4. I/O 操作基础

4.1 File 与路径

  • File 表示路径/文件，不等同于文件内容
  • 常用：exists()、mkdirs()、listFiles()

4.2 字节流 / 字符流

  • 字节流：InputStream / OutputStream（处理二进制）
  • 字符流：Reader / Writer（处理文本，带编码）
  • 包装缓冲：BufferedInputStream、BufferedReader 等

4.3 文本读取示例

4.4 序列化简述

  • Serializable 接口标记可序列化
  • 使用 ObjectOutputStream/ObjectInputStream
  • 注意：serialVersionUID，敏感信息与版本兼容

5. 并发与多线程（入门）

5.1 线程创建

  • 继承 Thread 或实现 Runnable / Callable

5.2 线程池（推荐）

  • ExecutorService，如 Executors.newFixedThreadPool(n)
  • 好处：复用线程、控制并发数量、统一管理

5.3 关键字与并发原语

  • synchronized：对象锁 / 类锁，保证原子性和可见性
  • volatile：仅保证可见性与有序性，不保证原子性
  • java.util.concurrent：CountDownLatch、Semaphore、并发容器等

5.4 JMM 与可见性

  • 线程对共享变量的读写可能被缓存
  • 通过 volatile、锁、原子类确保可见性 / 有序性 / 原子性

5.5 虚拟线程（JDK 19+）

  • 极轻量级线程，提升高并发下的伸缩性（项目需对应 JDK）

6. 网络编程基础

6.1 Socket

  • ServerSocket / Socket 进行 TCP 通信
  • 典型流程：监听端口 → 接受连接 → 输入输出流收发数据

6.2 HTTP 客户端

  • JDK 11+：java.net.http.HttpClient
  • 旧版：HttpURLConnection

6.3 正则表达式

  • Pattern、Matcher，用于字符串匹配与提取

6.4 NIO 与零拷贝（概念）

  • 通道（Channel）+ 缓冲区（Buffer）
  • Selector 支持多路复用
  • 零拷贝提升 IO 效率（FileChannel.transferTo/transferFrom）

7. 日期时间

7.1 旧 API

  • Date、Calendar，可变且线程不安全，API 可读性差

7.2 新 API（java.time，推荐）

  • 核心类：LocalDate、LocalTime、LocalDateTime、Instant
  • 时区：ZoneId、ZonedDateTime
  • 时间段：Period（日期）、Duration（时间）
  • 格式化：DateTimeFormatter
