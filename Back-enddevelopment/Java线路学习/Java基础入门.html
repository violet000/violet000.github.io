1. Java 代码结构与基本语法

1.1 一个最小可运行示例

关键要点：

  • 包声明：决定类的完整限定名（如 com.example.demo.HelloWorld）
  • 导入：import 引入其他包中的类；同包下可直接使用
  • 主类与 main：执行入口是 public static void main(String[] args)

1.2 关键字与标识符

  • 关键字：如 class、public、static、void、if、else 等，不能作为标识符使用
  • 标识符：类名、变量名、方法名等
    • 规则：字母、数字、下划线、$，不能以数字开头
    • 推荐命名规范：
      • 类名 / 接口名：大驼峰（StudentService）
      • 方法 / 变量：小驼峰（getName、userCount）
      • 常量：全大写 + 下划线（MAX_VALUE）

2. 数据类型与类型转换

2.1 基本数据类型（8 个）

  • 整型：byte(1)、short(2)、int(4)、long(8)
  • 浮点：float(4)、double(8)
  • 字符：char(2，Unicode)
  • 布尔：boolean(1，true/false)

括号内为字节数，浮点是近似存储，存在精度误差。

2.2 引用数据类型

  • 类（Class）、接口（Interface）、数组（Array）、枚举、注解等
  • 在堆上分配对象，变量存放引用地址

2.3 包装类型与默认值

  • 对应八大基本类型：Integer、Long、Double 等
  • 默认值：成员变量有默认值，局部变量必须先赋值

2.4 类型转换

  • 自动提升（小 → 大）：byte -> short -> int -> long -> float -> double
  • 强制转换（大 → 小）：可能溢出或精度丢失

计算时，byte/short/char 会先提升为 int，再参与运算。

3. 变量、作用域与常量

  • 成员变量：定义在类中，属于对象或类（若加 static）
  • 局部变量：方法内、代码块内、形参等，使用前必须赋值
  • 作用域：变量在其定义的块 {} 内可见
  • 常量：final 修饰的变量，赋值后不可变，通常配合 static 形成全局常量

4. 控制流（分支、循环、跳转）

4.1 条件分支

  • if / else if / else
  • switch：支持 byte/short/int/char/String/enum 等

4.2 循环

  • for、while、do-while
  • 增强 for（for-each）适用于数组与集合：

4.3 跳转

  • break：跳出最近一层循环 / switch
  • continue：跳过本轮，进入下一轮循环
  • return：结束方法

不建议使用带标签的 break/continue，可读性差。

5. 数组与集合入门

5.1 数组

  • 定长、同类型，支持快速随机访问
  • 初始化：

5.2 集合概览

  • List：有序、可重复（如 ArrayList、LinkedList）
  • Set：不重复（如 HashSet、TreeSet）
  • Map：键值对（如 HashMap、TreeMap）
  • Queue / Deque：队列 / 双端队列

选择建议：

  • 固定长度、基本类型 → 数组
  • 可变长度、频繁增删或需要丰富 API → 集合

6. 字符串与常用工具

6.1 字符串

  • String 不可变，适合做常量、Map 键
  • 可变拼接用 StringBuilder（单线程）或 StringBuffer（多线程）

常用操作：拼接、截取、查找、替换、分割

6.2 Math 常用方法

  • abs、pow、sqrt、round
  • max/min、random()（返回 [0,1)）

7. 方法与重载

  • 方法定义：[修饰符] 返回值 方法名(参数列表) { ... }
  • 方法重载：同名不同参（参数个数 / 类型 / 顺序不同，与返回值无关）

main 方法本质也是一个普通的静态方法，只是被 JVM 约定为入口。
