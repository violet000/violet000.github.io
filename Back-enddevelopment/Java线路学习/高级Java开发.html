1. 微服务与分布式架构

1.1 典型技术栈

  • Spring Cloud 全家桶：配置中心（Config）、注册发现（Eureka / Consul / Nacos）、网关（Gateway）、熔断限流（Resilience4j / Sentinel）、配置与链路追踪（Sleuth/Zipkin）
  • API 风格与协议：
    • RESTful API（HTTP + JSON）
    • GraphQL（前端聚合查询、按需取数）
    • gRPC（高性能二进制 RPC，HTTP/2）
  • 容器化与编排：
    • Docker：镜像、容器、镜像分层
    • Kubernetes：Deployment、Service、Ingress、ConfigMap、Secret、HPA

1.2 微服务关键治理点

  • 服务注册与发现：Eureka / Consul / Nacos
  • 配置中心：集中管理配置、动态刷新
  • 网关：统一入口、路由、鉴权、限流
  • 熔断 / 隔离 / 限流：防止雪崩（Resilience4j、Sentinel）
  • 链路追踪：Sleuth + Zipkin / SkyWalking，诊断调用链延迟与错误
  • 日志与监控：集中日志（ELK/EFK）、指标监控（Prometheus + Grafana）

2. 高性能与调优

2.1 JVM 与 GC 调优

  • 熟悉 JVM 运行时结构：堆、栈、方法区、JIT
  • 常见 GC 收集器：G1、ZGC、Shenandoah（理解 CMS/Parallel 作为对比）
  • 调优思路：
    • 监控：jmap/jstack/jstat、JFR、VisualVM、JMC
    • 调整堆大小、代大小、GC 算法与参数
    • 关注 GC 停顿时间与吞吐量的平衡

2.2 线程池与并发优化

  • 合理配置线程池参数（核心线程数、队列大小、拒绝策略）
  • 避免盲目创建线程，减少上下文切换
  • 使用并发容器与原子类，降低锁竞争
  • 对高并发场景，考虑分段锁、读写锁、无锁算法（LongAdder）等

2.3 缓存与中间件

  • Redis：KV 缓存、分布式锁、消息、位图、HyperLogLog、Geo
  • MQ（Kafka / RabbitMQ / RocketMQ）：削峰填谷、解耦、广播、顺序消费、延时消息
  • 搜索与分析：Elasticsearch / OpenSearch（全文检索、日志查询）

2.4 性能测试与优化闭环

  • 压测：JMeter / Locust / Gatling，关注 QPS / RT / 错误率
  • APM：Pinpoint / SkyWalking / ARMS 等
  • 性能瓶颈定位：CPU、内存、IO、锁、网络

3. 安全与认证

  • 认证 / 授权：JWT、OAuth2、SSO，结合 Spring Security 实现
  • 数据安全：加密（AES、RSA）、签名与验签、敏感信息脱敏
  • 接口安全：防重放、防刷、防注入（SQL 注入、XSS）、CORS
  • 传输安全：HTTPS、双向 TLS、证书管理

4. 架构与部署

4.1 典型架构关注点

  • 高可用：多副本、主从/主备、故障转移
  • 高扩展：水平扩容、无状态服务
  • 一致性：CAP/BASE 思想，幂等、补偿、分布式事务（Seata/TCC/可靠消息最终一致）
  • 观测性：日志、指标、Trace 三大支柱

4.2 容器化与 DevOps

  • 持续集成 / 持续交付（CI/CD）：Jenkins / GitHub Actions / GitLab CI
  • 基础设施即代码（IaC）：Helm、Kustomize、Terraform（了解）
  • 环境与配置：多环境配置、灰度发布、蓝绿发布、金丝雀

5. 学习路线建议（分层进阶）

5.1 初学者 → 进阶

  • Java 基础语法、OOP 核心、集合、异常、I/O、Lambda
  • 熟练使用 Spring Boot 构建 REST API，理解 MVC / DI / AOP 基本概念

5.2 进阶者 → 企业级开发

  • 持久化：JPA/Hibernate、MyBatis，事务与隔离级别
  • 测试：JUnit + Mockito + REST Assured；日志：SLF4J + Logback
  • 部署：打包成可运行 Jar / Docker 镜像，基础 Linux 运维命令

5.3 企业级 → 微服务与高并发

  • Spring Cloud / 服务治理、配置中心、网关、熔断限流
  • 消息队列、缓存、搜索引擎的组合使用
  • 基础分布式理论：CAP、BASE、幂等、重试与补偿

5.4 架构师向

  • 深入 JVM / GC / 并发模型
  • 观测性体系（日志/指标/Trace）、容量规划与性能压测
  • 可靠性工程：降级、限流、熔断、隔离、优雅停机；混沌工程（了解）
