模块与类

  • FRONT-ENDDEVELOPMENT

  • 模块与类

目标：掌握 CommonJS 与 ES6 模块的差异与使用场景，理解模块作用域/默认导出；熟练使用 class/constructor/静态成员/Getter/Setter/继承与组合，以及迭代器与生成器的基本用法。

1. 模块化

1.1 CommonJS（Node.js）

  • 语法：const mod = require('./mod');；导出用 module.exports = ... 或 exports.foo = ...。
  • 加载特性：同步加载，按需执行；在 Node 中模块文件仅执行一次，之后走缓存。
  • 值拷贝/引用：导出对象是引用，基本值拷贝值；循环依赖可能导出未完全初始化的内容。
  • 使用场景：Node.js 传统模块；打包工具会将 ESM 转 CommonJS 以兼容旧环境。

1.2 ES6 模块（ESM）

  • 语法：import / export；模块默认处于严格模式。
  • 加载特性：静态分析，编译期可确定依赖；浏览器/Node 均支持（需开启 ESM）。
  • 导出形式：
    • 命名导出：export const foo = 1; / export { foo, bar };
    • 默认导出：export default function () {}；导入可改名：import anyName from './mod.js'
    • 混合导出：同时有默认和命名导出。
  • 导入形式：
    • import { foo as alias } from './mod.js';
    • import * as mod from './mod.js';
    • 动态导入：const mod = await import('./mod.js');（返回 Promise，适合懒加载）。
  • 循环依赖：ESM 提供 live binding（活绑定），但初始化顺序仍可能出现暂时性未定义，需避免相互强耦合。
  • 浏览器落地：需 <script type="module">，默认延迟执行，支持 import.meta.url。

1.3 模块作用域与默认导出

  • 每个模块有自己的作用域，不会泄漏全局。
  • 默认导出每个模块只能有一个，导入时自定义名称：
    • export default function init() {}
    • import initApp from './app.js'
  • 命名导出可有多个，导入时需解构式：import { run, stop } from './runner.js'

1.4 CommonJS vs ESM 对照

  • 加载时机：CJS 运行时解析，ESM 编译期解析。
  • 执行/阻塞：CJS 同步；ESM 在浏览器是异步加载文件、按依赖顺序执行。
  • this：CJS 顶层 this === module.exports；ESM 顶层 this === undefined。
  • 导出绑定：CJS 导出的是拷贝/对象引用；ESM 是 live binding（导出变量变更会被导入方感知）。

2. 类与构造

2.1 class 与 constructor

  • class 是构造函数+原型的语法糖；方法定义在 Class.prototype 上。
  • constructor 用于初始化实例字段；未写会有默认空构造。
  • 类字段（实例字段）可直接写在类体内（新语法）：name = 'guest';

2.4 继承、super 与组合

  • 继承：class Sub extends Base { constructor(...) { super(...); } }
    • 在派生类构造中必须先 super() 再用 this。
  • 方法重写：同名方法覆盖；可在子类中使用 super.method() 调用父方法。
  • 组合优先：当“有一个”关系优先用组合而非继承，避免过深的继承树。

3. Generator 函数与迭代器

3.1 迭代器协议

  • 迭代器对象需实现 next()，返回 { value, done }。
  • 可选的 return/throw 用于提前结束或抛错。
  • 可迭代对象需实现 Symbol.iterator，返回一个迭代器。

3.2 生成器（Generator）

  • 语法：function* gen() { ... }；yield 产出值，next() 恢复执行。
  • 生成器天然实现迭代器协议（gen()[Symbol.iterator]() === gen()）。

3.3 迭代器/生成器的应用

  • 自定义可迭代数据结构。
  • 惰性序列（按需生成、节省内存）。
  • 与 for...of、解构、... 展开配合。
  • 可与 async 生成器（async function*）结合，用于流式异步数据（如分页、消息流）。

5. 速记

  • “CJS 同步 require 缓存结果；ESM 静态 import 活绑定。”
  • “模块默认严格模式，默认导出唯一，命名导出可多项。”
  • “class 仍是构造函数+原型；静态在构造上，实例在原型上。”
  • “extends 先 super 再 this；覆盖时可用 super.method 调父类。”
  • “生成器 function* + yield；迭代器协议是 next() => {value, done}。”***
