1. 集合类型总览

1.1 数组（Array）与类数组

1.1.1 数组的核心特性

  • 有序集合，索引从 0 开始。
  • length 属性可读写：增大 length 不会立刻分配元素，减小会截断。
  • 稀疏数组：中间缺元素（“空洞”），某些 API 行为不同（如 forEach 跳过空洞）。

1.2 Map 与 WeakMap

1.2.1 Map：键值对集合（键可以是任意值）

  • 传统对象 Object 的键会被转成字符串/symbol，而 Map 的键可以是任何值（包括对象）。

常用 API：

适用场景：

  • 需要非字符串键（如 DOM 节点、对象实例）。
  • 需要稳定的插入顺序遍历（迭代顺序即插入顺序）。

1.2.2 WeakMap：键是“弱引用”的对象

  • 键必须是对象（不能是原始值）。
  • 对键是弱引用：如果外部不再引用这个键对象，GC 可以回收，同时该条目会自动消失（不可观测何时）。
  • 不可遍历：没有 forEach、keys 等遍历方法。

典型用途：

  • 给对象“额外挂数据”而不影响其 GC（如为 DOM 元素存元信息）。

1.3 Set 与 WeakSet

1.3.1 Set：无重复值集合

  • 自动去重，值唯一（“SameValueZero” 比较，类似 === 但对 NaN 友好）。

常用 API：

典型用途：

  • 数组去重：const uniq = [...new Set(arr)];
  • 记录访问/选中状态等布尔集合。

1.3.2 WeakSet：仅存对象的“弱集合”

  • 元素必须是对象，弱引用，不可遍历。
  • 用途：标记对象是否“已处理/已访问”等，而不阻止 GC。

1.4 Typed Arrays（类型数组）

1.4.1 是什么

  • 二进制缓冲区视图，用于高性能数值运算、WebGL、音视频处理等。
  • 基于 ArrayBuffer：一块原始二进制缓冲区。
  • 各种视图类型：Int8Array、Uint8Array、Float32Array 等。

1.4.2 简单示例

特性：

  • 长度固定，不会像普通数组 dynamic growth 那样变化。
  • 只存数值，类型固定，无空洞。
  • 对底层内存布局更可控，便于与底层/原生交互。

2. JSON：数据交换格式

2.1 JSON 格式与语法

2.1.1 基本规则

  • 基于 JS 对象字面量的子集，但更严格：
    • 字符串必须用双引号 "。
    • 键（属性名）必须是双引号包裹的字符串。
    • 不允许尾随逗号。
    • 不能出现 undefined、NaN、Infinity、函数、Symbol 等。

2.2.1 JSON.parse(text, reviver?)

  • 把 JSON 字符串解析为 JS 值。
  • 参数 reviver(key, value) 可对解析结果二次处理（递归遍历）。

异常处理：

2.2.2 JSON.stringify(value, replacer?, space?)

  • 把 JS 值序列化为 JSON 字符串。
  • 非 JSON 支持类型（如 undefined、函数、Symbol）：
    • 在对象属性中会被忽略；
    • 在数组中会被转为 null。
  • replacer：
    • 可以是函数 (key, value)，或属性键数组（决定哪些键会被序列化）。
  • space：
    • 控制缩进（如 2 或 '\t'），便于人类阅读。

2.2.3 常见坑

  • 循环引用会导致 TypeError：
  • Date 会被转成 ISO 字符串，恢复需手动 new Date(value) 或用 reviver。
  • 大整数（超出 2^53-1）在 JS 中无法精确表示，序列化前需用字符串或 big-int 方案。

4. 速记

  • “数组有序可变长，类数组长得像但没方法。”
  • “Map 键任意值，WeakMap 键必须对象且弱引用（不可遍历）。”
  • “Set 去重看 SameValueZero，WeakSet 只装对象也弱引用。”
  • “TypedArray 固定长度、数值专用，适合高性能场景。”
  • “JSON 只认双引号、无函数无 undefined，parse/stringify 搭配 reviver/replacer 更灵活。”***
