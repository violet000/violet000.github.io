对象与原型系统(原型链、原型对象)

  • FRONT-ENDDEVELOPMENT
  • JAVASCRIPT基础
  • 对象与原型系统

目标：掌握对象的创建、属性特性、原型与原型链、各类继承方式，以及 ES6 类语法的本质与坑点。

1. 对象基础与属性特性

1.1 对象的定义方式

  • 对象字面量：const obj = { a: 1, fn() {} };
  • 构造函数 + new：function Person(name) { this.name = name; } const p = new Person('A');
  • **Object.create(proto, props?)**：以指定原型创建对象，可同时定义属性描述符。
  • 类（class）：class User { constructor(name) { this.name = name; } }

1.2 属性类型与特性（属性描述符）

  • 数据属性：value、writable、enumerable、configurable。
  • 访问器属性：get、set（没有 value/writable）。
  • 获取/定义描述符：
    • Object.getOwnPropertyDescriptor(obj, 'key')
    • Object.defineProperty(obj, 'key', { value, writable, enumerable, configurable })
  • Object.defineProperties(obj, { a: {...}, b: {...} }) 批量定义。

1.3 可枚举性与遍历

  • for...in 遍历可枚举的自有 + 继承属性（需用 hasOwnProperty 过滤）。
  • Object.keys()：自有可枚举键。
  • Object.getOwnPropertyNames()：自有字符串键（含不可枚举）。
  • Object.getOwnPropertySymbols()：自有 symbol 键。
  • Reflect.ownKeys()：自有全部键（字符串 + symbol）。

1.4 对象冻结/密封/扩展控制

  • Object.preventExtensions(obj)：禁止新增属性。
  • Object.seal(obj)：在 preventExtensions 基础上把现有属性设为 configurable:false。
  • Object.freeze(obj)：再加 writable:false，形成只读浅冻结。
  • 深冻结需递归处理。

2. 构造函数、实例与原型

2.1 构造函数与实例关系

  • 使用 new Fn() 会做 4 步：
    1. 创建空对象；
    2. 该对象内部 [[Prototype]] 指向 Fn.prototype；
    3. 执行构造函数，this 绑定到新对象；
    4. 若构造函数返回对象则用返回值，否则返回新对象。

2.2 原型对象（prototype）与实例原型（[[Prototype]]/__proto__）

  • Fn.prototype：构造函数的原型对象，供实例查找共享成员。
  • 实例的内部槽 [[Prototype]]（多数实现暴露为 __proto__）指向构造函数的 prototype。
  • 推荐用 Object.getPrototypeOf(obj) / Object.setPrototypeOf(obj, proto)，避免直接用 __proto__（性能与可移植性考虑）。

2.3 原型链查找规则

  • 读取属性时：先查自有属性；无则沿 [[Prototype]] 一层层向上；直至 null 停止；找不到则 undefined。
  • 方法共享：把方法定义在原型上可节省内存。
  • 写入属性：默认在实例自身创建/修改同名自有属性（不会自动写到原型）。

2.4 判断关系

  • obj.hasOwnProperty('key')：是否为自有属性。
  • 'key' in obj：自有或继承均返回 true。
  • obj instanceof Ctor：检查原型链上是否能找到 Ctor.prototype。
  • Object.prototype.isPrototypeOf(obj)：当前原型是否出现在 obj 的原型链上。

3. 内建对象与原型

  • 所有构造器（Object/Array/Function/Date/RegExp/Map/Set 等）本质也是函数，拥有自己的 prototype。
  • 典型链条示例（浏览器/Node 均类似）：
    • 数组实例 arr → Array.prototype → Object.prototype → null
    • 函数实例 fn → Function.prototype → Object.prototype → null
    • Function.prototype 自己也是函数，因此其内部 [[Prototype]] 是 Object.prototype。
  • 修改内建原型（猴子补丁）需谨慎：可能破坏第三方库或未来标准。推荐用自定义工具函数替代。

4. 继承方式详解

4.1 原型式继承（基于对象）

  • 核心：以某对象为原型创建新对象。
  • 现代写法：const child = Object.create(parent);
  • 适合：快速克隆原型链结构；缺点：共享引用类型属性可能导致污染。

4.2 构造函数继承（借用构造函数）

  • 在子类型构造中调用父构造：Parent.call(this, args...)。
  • 优点：避免共享父级引用属性。
  • 缺点：无法复用父原型上的方法（只继承实例属性）。

4.3 组合继承（构造函数继承 + 原型继承）

  • 步骤：
    1. 子构造内部 Parent.call(this, ...) 继承实例属性；
    2. Child.prototype = Object.create(Parent.prototype);
    3. Child.prototype.constructor = Child;
  • 优点：继承实例属性 + 共享方法。
  • 缺点：父构造执行两次（一次给原型，一次给实例），可用寄生组合优化。

4.4 寄生组合式继承（推荐的 ES5 写法）

  • 避免多次调用父构造：
  • 子构造里 Sup.call(this, ...) 一次，原型链通过 Object.create 连接，无二次调用。

4.5 ES6 类与 extends

  • class 是语法糖，本质仍是构造函数 + 原型。
  • extends 自动建立原型链：
    • SubClass.prototype.__proto__ === SuperClass.prototype
    • SubClass.__proto__ === SuperClass
  • 子类构造中必须先 super() 才能访问 this（在派生类中）。
  • 静态属性/方法不会被实例继承，但会被子类继承（extends 也连接构造器的原型链）。
  • 类方法定义在 Class.prototype 上；类字段（实例字段）在构造执行时赋值到实例。

4.6 super 的含义

  • 在构造函数中：调用父类构造，初始化 this。
  • 在实例方法中：super.method() 等价于 Parent.prototype.method.call(this)。
  • 在静态方法中：super.method() 指向父类构造函数的静态方法。

5. 常见坑与排错

  • **误用 __proto__**：调试可用，生产推荐 Object.getPrototypeOf/SetPrototypeOf，或在创建时用 Object.create。
  • 共享引用属性：原型上的对象/数组会被所有实例共享，需在构造函数内初始化独立副本。
  • 忘记重设 constructor：Child.prototype = Object.create(Parent.prototype) 后记得 Child.prototype.constructor = Child。
  • super 调用顺序：派生类构造中未先调用 super() 就用 this 会抛错。
  • 修改内建原型：可能破坏生态；若必须，确保幂等与安全检查。
  • instanceof 与多环境：跨 realm（如 iframe）时 instanceof 可能失效，可改用 Object.prototype.toString.call(value) 或鸭子类型检查。

  • “构造四步：建对象、连原型、绑 this、看返回。”
