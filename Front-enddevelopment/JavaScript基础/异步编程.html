异步编程

  • FRONT-ENDDEVELOPMENT
  • JAVASCRIPT基础
  • 异步编程

目标：掌握事件循环、回调地狱的根源、Promise/async-await 的用法与错误处理，了解常用并发工具与函数式组合（含柯里化）在异步中的应用。

1. 同步与异步、事件循环

1.1 同步 vs 异步

  • 同步：一行一行执行，阻塞后续（如长循环、同步 I/O）。
  • 异步：把任务交给引擎/线程池/宿主，当前栈清空后再回调（如定时器、网络请求、DOM 事件）。

1.2 事件循环（Event Loop）概览

  • 调用栈：执行同步代码，栈清空后处理队列。
  • 宏任务队列：如 setTimeout、setInterval、I/O、script。
  • 微任务队列：如 Promise.then/catch/finally、queueMicrotask、MutationObserver。
  • 顺序：同步 → 清空微任务 → 取 1 个宏任务 → 再清空微任务 → 循环。
  • 动画与渲染：浏览器在宏任务间可能执行渲染，requestAnimationFrame 在帧前执行。

1.3 回调函数与回调地狱

  • 回调地狱根源：深层嵌套、错误传递困难、控制流分散。
  • 缓解手段：拆函数、命名回调、用 Promise/async-await、用组合工具（串行/并行控制）。

2. 异步方案逐项实战

2.1 定时器：setTimeout / setInterval

  • setTimeout(fn, delay, ...args)：最少延时，不保证精确时间；嵌套递归 setTimeout 可替代 setInterval，便于控制漂移。
  • setInterval 易累积漂移/重入，需在回调内防重入或改用递归 setTimeout。
  • 取消：clearTimeout(id) / clearInterval(id)。
  • 常见坑：最小延时在部分环境约 4ms；页面后台或节流模式下延时会被拉长。

2.2 Promise 基础与链式调用

  • 三态：pending → fulfilled/rejected；状态不可逆。
  • 链式：then/catch 返回新 Promise，可返回值或 Promise；返回普通值会包成 fulfilled，抛错/返回 rejected Promise 会进入拒绝。
  • 错误冒泡：链中抛出的错误会被后续最近的 catch 捕获；未捕获会触发 unhandledrejection。
  • finally：无论成功/失败都会执行；返回值会被忽略，除非抛错使链进入拒绝。

2.3 async/await

  • async 函数返回 Promise；内部 throw 等价于返回 rejected Promise。
  • await 等待 Promise 解析；只能在 async 中（或顶层 ES 模块）。

  • 错误捕获：try...catch 包裹，或用 await xxx().catch(...)。

2.4 并发工具：Promise.all / race / allSettled / any

  • Promise.all：任一拒绝则整体拒绝，成功返回按顺序的数组。
  • Promise.race：第一个 settle（无论成功失败）就返回。
  • Promise.allSettled：等全部 settle，返回每项 {status, value|reason}。
  • Promise.any：任一 fulfilled 即返回；若全拒绝抛 AggregateError。
  • 常见用法：并行请求、超时控制（race 一个超时 Promise）、部分成功处理（allSettled）。

2.5 异步错误处理

  • Promise 链：使用结尾 catch，必要时中间分支也 catch。
  • async/await：try...catch 或封装 wrap 函数返回 [err, data]。
  • 监听全局：浏览器 window.addEventListener('unhandledrejection', ...)；Node process.on('unhandledRejection', ...)。

2.6 柯里化与函数组合在异步中的应用

  • 柯里化：把多参函数拆为一系列一参函数，便于部分应用与复用。
  • 组合（compose/pipe）：将多个函数从右到左（compose）或左到右（pipe）组合。
  • 价值：消除深嵌套，形成线性异步流程。

5. 速记

  • “同步阻塞栈，异步排队等栈空；微任务优先于宏任务。”
  • “Promise 链返回值自动包；抛错/拒绝走最近 catch。”
  • “async 返回 Promise，await 只在 async 里用；并行用 all，超时用 race。”
  • “回调地狱不怕：拆函数、Promise 化、async 化、再加组合/管道。”
  • “定时器不精确，递归 setTimeout 可控；后台标签页会被节流。”***
